# LLM Bootcamp

Static website for the LLM Bootcamp, served with GitHub Pages.

## Editing

All content is in `index.html`; styles are in `style.css`. Search for `[` to find placeholders that still need real details.

To preview locally:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

## Publishing

In the repository on GitHub, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, then pick `main` / `(root)`.
